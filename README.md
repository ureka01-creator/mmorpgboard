# ELDERFALL · 잊힌 맹세

대화, 동료, 탐험과 턴제 전투를 중심으로 만드는 **오리지널 파티 RPG**입니다. 기존 보드게임은 교체했으며 Git 이력에 남아 있습니다. 특정 작품의 세계관·캐릭터·규칙을 복제하지 않습니다.

**플레이:** https://ureka01-creator.github.io/mmorpgboard/?release=1.0

첫 번째 모험에서는 버들강 마을의 임무를 받고 검사·마법사·치유사로 파티를 구성해 유적의 수호석을 되찾습니다. 마을과 유적 두 장소, 대화 선택과 설득 판정, 벽과 시야, 영웅별 AP, 속박·방어·치유, 후퇴·야영, 자동 저장과 결말이 연결된 작은 시제품입니다. 대형 상용 CRPG의 완성도를 구현한 버전은 아닙니다.

## 조작

- 빈 칸을 눌러 일행을 이동합니다. 인물·야영지·출구를 누르고 가까이 이동한 뒤 상호작용하세요.
- 촌장에게 임무를 받고 리엔과 세라를 동료로 모으세요. 마을 동쪽 길로 유적에 들어갑니다.
- 전투에서는 파티 카드로 영웅을 선택하세요. 이동 한 칸 AP 1, 공격·기술 AP 2, 방어 AP 1. 각 영웅은 AP 4를 따로 사용합니다.
- 공격 모드에서 적을 누릅니다. 마법사의 기술은 적, 치유사의 기술은 아군을 지정합니다. 기술은 집중을 1 사용합니다. 검사의 회전 베기는 인접한 모든 적에게 적용됩니다.
- 영웅의 행동을 마친 뒤 ‘적 차례’를 누릅니다. 적이 이동·공격하고 영웅의 AP가 회복됩니다.
- 적을 처치하고 북동쪽 수호석을 회수하세요. 마을로 돌아가 촌장에게 보고하면 완료됩니다.
- ‘모험 일지’에 규칙과 실제 기록이 있습니다. 새 모험은 확인 후 현재 저장을 교체합니다.

저장은 해당 브라우저의 `localStorage`에 남습니다. 이전 보드게임 저장 키는 건드리지 않습니다. 클라우드 저장·온라인 멀티플레이는 지원하지 않습니다. 게임은 화면에 맞춰 배치하며 긴 대화·일지는 패널 내부에서 스크롤합니다.

## 개발과 검증

런타임 의존성이나 빌드가 없는 HTML/CSS/JavaScript 앱입니다. 기존 체크아웃에서 작업합니다. 설치, 별도 Git worktree, 서버 백엔드가 필요하지 않습니다.

```sh
cd /workspace/mmorpgboard
python -m http.server 8004 --bind 127.0.0.1
```

내부 점검용 서버입니다. 공개 플레이는 위 GitHub Pages 주소를 사용합니다.

```sh
node scripts/verify_rpg.cjs
python scripts/verify_rpg_browser.py
```

브라우저 검증은 Python Playwright와 `/usr/bin/chromium`을 사용합니다. `RPG_BASE` 환경변수로 점검 대상을 바꿀 수 있습니다. 테스트 스크린샷은 `docs/screenshots`에 기록됩니다. 공개 배포는 `python scripts/verify_public.py`로 파일 해시와 기능을 점검합니다. 자세한 범위는 [검증 기록](docs/verification.md)을 확인하세요.

- `rpg-engine.js`: 탐험, 대화, 경로, 시야, AP, 판정, 적 행동, 상태 검증. 실패한 행동은 상태를 바꾸지 않습니다.
- `app.js`: 터치 UI와 자동 저장. 판정 결과를 먼저 저장하고 연출을 표시해 중복 행동과 재추첨을 막습니다.
- `index.html`, `styles.css`: 화면과 반응형 배치.
- `assets`: 오리지널 생성 배경·일러스트.

다음 제작 방향은 [섹션별 기획](docs/rpg-plan.md)에 정리했습니다.
