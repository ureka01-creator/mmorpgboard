# 엘더폴: 마지막 레이드 v0.3

**아이패드 한 대에서 1~4명이 함께하는 서양 판타지 협동 보드게임**. 같은 화면에서 차례를 넘기며 플레이합니다. 인쇄나 실물 주사위가 필요하지 않습니다.

## 실행

별도 앱 설치·계정·API 없이 정적 웹사이트로 동작합니다. 저장소 루트에서 개발 서버를 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

아이패드 Safari에서 플레이하려면 `index.html`, `styles.css`, `game-engine.js`, `app.js`와 `assets/` 폴더을 정적 웹 호스팅에 올리고 해당 HTTPS 주소를 여세요. `docs/elderfall-web.zip`은 웹 파일과 두 일러스트를 묶은 배포용 압축 파일입니다. 공개 플레이 주소: **https://ureka01-creator.github.io/mmorpgboard/**. 개발 서버의 루프백 주소는 다른 기기에서 접속할 수 없습니다. 로컬 파일 직접 열기는 브라우저 보안 정책에 따라 차단될 수 있어 웹 호스팅을 권장합니다.

## 플레이 방향

월드 오브 워크래프트 보드게임의 세계 탐험·퀘스트·성장 흐름을 참고합니다. 엘더폴은 자체 세계관과 영웅을 사용하는 시제품입니다. 원작 규칙 전체를 구현한 게임은 아닙니다.

## 기능

- 직업 4종 선택, 터치 이동, 자동 주사위·피해 계산
- 직업 능력, 치유, 방어, 적 단계, 부활
- 봉인, 공유 경험치, 전리품 배분·사용·전달, 용 소환, 자동 승패
- 일러스트 월드맵, 직업 초상화와 지도 위 영웅 말
- 세 지역의 퀘스트 일지, 목표 선택과 지도 표시, 완료·보상 안내
- 게임 목표 설명, 첫 이동과 전투 안내, 추천 이동 칸 강조
- 가능한 이동 칸 강조, 상황에 따른 행동 비활성화, 다음 목표 안내
- 현재 브라우저 자동 저장과 이어하기. 저장 실패 시 화면에 안내

전투는 로컬에서 처리합니다. 온라인 멀티플레이와 기기 간 동기화는 없습니다. 같은 호스팅 주소와 브라우저에서 이어할 수 있으며 데이터 삭제 또는 사생활 보호 모드에서 진행 기록이 사라질 수 있습니다.

## 검증

```sh
node scripts/verify_engine.cjs
# 개발 서버를 먼저 실행하세요. 테스트에 Playwright 및 Chromium이 필요합니다.
python3 scripts/verify_browser.py
```

게임 엔진 13개 시나리오와 터치 Chromium 기능 검사 48개 통과. 검사에는 시작부터 세 지역·전리품·성장·용 소환·승리까지의 전체 1인 플레이와 저장·재시작, 4인 차례 교대가 포함됩니다. 전체 플레이 검사는 고정된 주사위 결과를 사용하므로 난이도 균형을 입증하지 않습니다. 320~1366px 화면 폭에서 가로 넘침 없음. 실제 iPad Safari와 사람 간 플레이 시간·밸런스는 미검증입니다.

[규칙서](docs/rules.md). 기존 `docs/elderfall-print.pdf`는 v0.1 실물 시제품의 보관 자료이며 현재 디지털 플레이에는 필요하지 않습니다.
