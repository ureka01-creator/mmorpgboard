# ELDERFALL · 3D 이동과 공격

**플레이:** https://ureka01-creator.github.io/mmorpgboard/?release=1.1

현재 제작 범위는 실제 3D 공간에서 **걷기 → 적에게 접근 → 검 공격 → 피격**을 연결하는 한 장면입니다. 기둥을 피하는 경로, 실제 뼈대 애니메이션, 타격 시점의 피해, 수호병 반격과 쓰러짐을 확인할 수 있습니다. 대화·파티·퀘스트·장비 같은 부가 기능은 이번 화면에 없습니다.

현재 모델은 움직임을 검증하는 임시 KayKit 자산입니다. [목표 화면 시안](docs/screenshots/3d-target-concept.png)은 이미지 생성으로 만든 아트 디렉션 참고자료이며 **실제 플레이 화면이 아닙니다**. 목표로 하는 사실적인 캐릭터와 정교한 환경은 별도 모델·재질·애니메이션 제작/확보가 필요합니다. 현재 동작 검증판의 그래픽과 목표 시안을 같은 품질로 설명하지 않습니다.

## 조작

- 바닥을 누르면 경로를 따라 이동합니다. 기둥 사이를 대각선으로 관통하지 않습니다.
- 수호병을 누르거나 ‘수호병에게 접근해 공격’을 누르면 가까이 걸어간 뒤 검을 휘두릅니다.
- 타격 동작의 중간에 적의 체력이 줄어듭니다. 살아 있는 적은 반격합니다. 동작 중 추가 클릭은 중복 공격을 만들지 않습니다.
- 드래그로 카메라를 회전합니다. 두 손가락으로 확대/이동하고 상단 버튼으로 회전하거나 기사에 시점을 맞출 수 있습니다.
- ‘다시 시작’으로 위치와 체력을 초기화합니다. 소리를 끄고 켤 수 있습니다.

첫 장면은 자동 저장이나 성장 시스템을 포함하지 않습니다. 새로고침하면 처음부터 시작합니다. 이전 보드게임과 2D RPG는 Git 이력에 있으며 기존 브라우저 저장 키는 삭제하지 않습니다.

## 실행과 검증

HTML/CSS와 JavaScript ES 모듈, WebGL/Three.js를 사용합니다. Three.js는 검증된 0.180.0 패키지에서 필요한 파일을 저장소에 포함했습니다. npm 설치, 빌드, 외부 CDN 연결이나 서버 백엔드가 필요하지 않습니다. 기존 체크아웃에서 작업합니다. 최신 WebGL 2 및 import map 지원 브라우저가 필요합니다.

```sh
cd /workspace/mmorpgboard
python -m http.server 8004 --bind 127.0.0.1
```

내부 검증용 서버입니다. 공개 플레이는 위 GitHub Pages 주소를 사용합니다.

```sh
node scripts/verify_arena.mjs
python scripts/verify_arena_browser.py
```

브라우저 검증은 Python Playwright와 `/usr/bin/chromium`을 사용합니다. 클라우드의 소프트웨어 WebGL로 실제 스키닝·이동·타격·피격·사망과 입력을 확인합니다. `ARENA_BASE`로 내부 점검 대상을 바꿀 수 있습니다. 실제 iPad Safari 및 기기 성능은 별도 확인이 필요합니다.

- `arena-engine.mjs`: 좌표, 장애물, 경로, 접근, 공격과 반격 규칙.
- `arena.js`: 실제 3D 장면, 카메라, 리깅 애니메이션, 순차 동작과 UI.
- `arena.css`, `index.html`: 최소 조작 화면.
- `assets/3d`: CC0 캐릭터/무기, 원본 라이선스와 출처/해시 기록.
- `vendor/three`: Three.js 모듈과 MIT 라이선스.

모델·애니메이션 출처는 [자산 기록](docs/3d-assets.md), 검증 범위는 [검증 기록](docs/verification.md), 남은 아트 작업은 [품질 점검](docs/quality-review.md)에 있습니다.
