# 엘더폴: 잿빛 왕국의 영웅들 v0.7

아이패드 한 대에서 1~4명이 차례를 넘기며 즐기는 자체 판타지 협동 캠페인 보드게임. 2005년 FFG 《월드 오브 워크래프트 보드게임》의 세계 여행·퀘스트·직업 성장·장비·주사위 구성에서 영감을 받았습니다. 원작의 규칙이나 진영 경쟁을 그대로 구현한 게임은 아닙니다.

**플레이: https://ureka01-creator.github.io/mmorpgboard/?release=0.7**

시안을 바탕으로 탐험·전투·보상 화면과 기술 배치 전투를 개편했습니다. [섹션별 기획안](docs/redesign-plan.md)의 전체 캠페인 확장·기술 장착 슬롯·위협 트랙 개편은 후속 단계입니다.

## 이번 캠페인

20라운드 안에 잿빛 용을 처치하세요. 먼저 약초 수집과 상단 호위로 장비와 특성을 얻고, 지역 보스를 공략해 봉인 2개를 확보합니다. 현재 영웅 레벨 3부터 마지막 레이드에 도전할 수 있습니다. 세 번째 봉인을 얻으면 용의 체력이 감소합니다.

- 16개 실제 지역과 20개 연결 경로, 마을·야영지·항구의 회복·보급 거점 3곳
- 도로·다리로 안전하게 돌아가거나 보급·체력을 쓰는 여울·고개·위험한 비탈 선택
- 이동 비용 미리보기와 하단 확정 버튼, 목표·거점까지 안전/행동 절약 경로 비교
- Lv.2 고개, 적 처치 후 열리는 진행 통로, Lv.3·봉인 2개 조건의 용 둥지 진입
- 수집·호위·사냥 퀘스트 7종, 영웅별 동시 수락 3개, 거점 보고와 장비 보상 선택
- 개인 경험치와 골드, 레벨 1~4, 직업 4종의 특성 24개(직업당 6개)
- 지속 장비 12종, 무기·갑옷·장신구 슬롯, 상점·보급·물약·동료 장비 전달
- 장비·특성에 따라 달라지는 공격·마법·방어 주사위 구성
- 지도 중심 탐험 화면, 별도 전투 테이블, 삽화가 있는 기술·장비 카드와 보상 비교 화면
- 직업별 기본 기술 3개와 Lv.3 기술 1개: 주사위 배치로 공격·보호·치유·적 약화 선택
- 배치한 주사위의 기본 기여 제거, 기술 에너지 예약·확정, 교전별 재사용 대기
- 여섯 면과 눈이 있는 CSS 입체 주사위, 굴림과 공격→적 반격 연출, 빠른 연출·동작 줄이기
- 영웅별 강습·집중·방어·회복 준비, 별도 재굴림 모드, 반격 후 체력까지 미리보기
- 기존 기록을 덮어쓰지 않는 기사 전투 체험: 첫 굴림은 기술 배치를 배우는 고정 예시
- 갑옷·마법 저항·출혈·재생·에너지 저주, 광역 공격과 격노를 가진 용
- 같은 지역의 동료가 함께 전투, 참여 인원에 따른 적 체력, 참여 영웅의 전투 경험치
- 3라운드마다 세계 사건 6종, 에너지·체력·골드·보급과 여행 행동 관리
- 페이지 스크롤 없는 지도와 전투 테이블, 긴 카드 목록은 팝업 내부에서 열람
- 새 `elderfall-campaign-v3` 키에 자동 저장, 기존 v2 캠페인·진행 중 전투 이어하기. v0.5 캠페인은 성장·장비를 유지해 새 지도로 업그레이드하고 기존 기록을 백업. 이전 v0.4 기록도 보존

1인 전투와 협동 캠페인을 구현한 초기 버전입니다. 진영 간 경쟁, 온라인 멀티플레이, 직업별 대규모 기술 덱과 다중 보스 캠페인은 현재 범위에 포함되지 않습니다. 그림과 세계관은 엘더폴의 자체 자산을 사용합니다.

## 개발

HTML/CSS/JavaScript로 만든 정적 웹게임입니다. 앱 서버, 데이터베이스, 계정 또는 API 키가 필요 없습니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
node scripts/verify_engine.cjs
node scripts/verify_tactics.cjs
python3 scripts/verify_browser.py
ELDERFALL_TEST_URL=http://127.0.0.1:8000/ python3 scripts/verify_redesign_browser.py
node scripts/simulate_balance.cjs
node scripts/simulate_tactics.cjs
```

화면 검사는 Python Playwright와 `/usr/bin/chromium`을 사용합니다. `ELDERFALL_TEST_URL`로 대상 주소를 지정할 수 있습니다. `docs/elderfall-web.zip`에는 웹 파일과 `assets/`가 포함됩니다. main 업로드와 gh-pages 배포는 별개이며 [배포 설명](docs/deployment.md)을 참고하세요.

## QA

캠페인 엔진 37개·기술 전투 14개 시나리오, 기존 터치 Chromium 138개·개편 화면 82개 검사 통과. 퀘스트·장비·특성·봉인·용 처치의 전체 UI 플레이, 상점과 동료 전달, 전투 중 저장·재굴림·후퇴, 차례 순환, 손상 기록 처리를 검증했습니다. 320~1366px 화면에서 지도·전투·파티·핵심 행동 조작이 화면 안에 들어옵니다.

전체 캠페인 검사는 고정된 좋은 주사위를 사용해 기능 경로를 검증합니다. 별도 수치 시뮬레이션은 직업당 300회, 총 1,200회의 시드 고정 용 전투를 실행합니다. 최고 레벨의 공격 특성과 영웅 무기를 지급한 조건이며 실제 캠페인 난이도·재미를 입증하지 않습니다. 새 기술 비교는 장비 없는 Lv.1 늑대 전투에서 직업 4종×정책 3종×200회, 총 2,400회입니다. 공격·생존 정책에서 첫 적 승률이 높아 입문용으로 쉽다는 점을 확인했으며, 전체 캠페인 난이도는 별도 조정 대상입니다. 실제 iPad Safari와 사람의 장기 플레이 밸런스는 추가 검증이 필요합니다.
