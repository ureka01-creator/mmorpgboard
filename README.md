# ELDERFALL · 잊힌 성역

**플레이:** https://ureka01-creator.github.io/mmorpgboard/?release=2.5

녹스의 높은 시점과 직접 조작하는 액션 감각을 참고한 **실제 3D 실시간 던전 전투**입니다. 원작의 그림·캐릭터·UI를 복제하지 않습니다. 첫 범위는 성역 한 구역, 방과 연결 통로, 기사 한 명과 수호병 한 명의 이동·검격·회피입니다.

2.5는 남색 천옷, 가죽 장비, 철제 어깨 갑옷, 얼굴과 짧은 머리, 짧은 망토를 가진 새로운 Sentinel 아트를 사용합니다. 원본 CC0 스킨을 바탕으로 신체 비례와 얼굴·장비·표면을 다시 제작했고, 사진 텍스처를 원작 화풍을 참고한 독자 색과 표면으로 교체했습니다. 전체 53개 관절, 짧은 보폭과 접지 위상, 이동 중 공격과 뒷걸음을 유지합니다.

몸의 상하 접지 보정을 천천히 적용하고 지면 아래로 내려가는 발은 다리에서 보정합니다. 손목의 무기 잡기는 유지하면서 어깨에는 보행 움직임을 더 허용합니다. 회피는 버튼을 누르는 즉시 이동 방향으로 실행되며, 이동 패드를 계속 누르면 회피 뒤 바로 걷습니다. 회피의 마지막 구간은 보행 자세로 섞어 연결합니다.

## 조작

- 아이패드: 왼쪽 이동 패드를 끌어 직접 이동합니다. 오른쪽 검격 버튼을 누르거나 유지해 공격하고, 회피 버튼으로 구릅니다. 이동 패드를 누른 채 다른 손가락으로 공격하거나 회피할 수 있습니다. 회피 버튼은 누르는 순간 실행되고, 이동 입력을 유지하면 회피가 끝나자마자 걷습니다.
- PC: WASD 또는 방향키로 이동, Space로 검격, Shift로 회피, P/Escape로 일시 정지합니다.
- 바닥 탭으로 목적지까지 이동할 수도 있습니다. 벽과 기둥을 돌아가는 실제 경로를 사용합니다.
- 검격 버튼은 자동 접근하지 않습니다. 검이 닿는 거리에 직접 들어가야 합니다. 적이 검을 들면 준비 동작과 바닥의 공격 방향을 보고 범위 밖으로 이동하거나 회피하세요.
- 수호병은 실제로 추격하며 준비 → 검격 → 회복을 반복합니다. 공격이 명중해야만 체력이 줄어듭니다. 회피는 짧은 무적 시간과 재사용 대기시간이 있습니다.
- 상단에서 소리, 정지, 다시 시작을 조작합니다. 탭 전환/화면 이탈 때는 자동으로 정지합니다.

인벤토리·마법·파티·퀘스트·저장·문 상호작용은 이번 범위에 없습니다. 문은 열린 장식이며 계단은 다음 공간의 아트 표현입니다. 새로고침하면 처음부터 시작합니다.

## 아트와 실행

실제 WebGL/Three.js로 방, 벽, 문, 기둥, 깃발, 횃불, 바닥 문양과 통로를 렌더링합니다. Luana Coppio의 CC0 기사 스킨을 바탕으로 신체 비례를 조정하고, 머리·망토·장비와 색·표면을 새로 제작했습니다. Quaternius의 CC0 동작을 새 53관절 바인드에 맞춰 변환합니다. 기사와 수호병은 색과 장비가 다른 인스턴스이며 뼈대와 재질을 독립적으로 사용합니다. 이전 KayKit 모델은 현재 장면에서 사용하지 않습니다. 목표 시안은 참고 이미지이며 현재 렌더와 같은 품질을 구현했다고 설명하지 않습니다.

HTML/CSS와 JavaScript ES 모듈, vendored Three.js 0.180.0을 사용합니다. npm 설치·빌드·외부 CDN·서버 백엔드가 필요하지 않습니다. 기존 체크아웃에서 개발합니다.

```sh
cd /workspace/mmorpgboard
python -m http.server 8020 --bind 127.0.0.1
```

내부 검증 서버입니다. 공개 플레이는 위 GitHub Pages 주소를 사용합니다.

```sh
node scripts/verify_arena.mjs
node scripts/verify_motion.mjs
python scripts/verify_motion_browser.py
python scripts/verify_arena_browser.py
```

브라우저 검증은 Python Playwright와 `/usr/bin/chromium`을 사용합니다. `ARENA_BASE`로 내부 점검 주소를 바꿀 수 있습니다. 소프트웨어 WebGL의 기능 검증을 실제 iPad Safari의 성능 검증으로 간주하지 않습니다.

- `arena-engine.mjs`: 연속 좌표, 충돌, 경로, 실시간 공격/회피와 적 행동.
- `arena.js`: 고정 카메라, 터치/키보드 조작, 정지/재시작, 시뮬레이션과 연출 연결.
- `arena-actors.mjs`: 독립적인 스킨 모델, 자세 혼합·접지·검 궤적.
- `arena-motion.mjs`: 프레임 간격에 독립적인 혼합과 방향 전환.
- `arena-clips.mjs`, `assets/characters`, `assets/animations`: CC0 동작 로딩·보간·타격 시간 매핑과 출처/라이선스.
- `arena-art.mjs`: 던전 구조, 생성 표면 맵, 재질·조명·초상 렌더.
- `arena.css`, `index.html`: 화면을 가리지 않는 조작 UI.
