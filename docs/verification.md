# 2.0 실시간 던전 검증

2026-10-11 · Node 24 · Python Playwright/Chromium SwiftShader WebGL.

## 시뮬레이션

`node scripts/verify_arena.mjs`: 16개 규칙 테스트 통과.

벽·기둥·소품 충돌, 고속 회피의 관통 방지, 연결 통로, 경로의 모서리 충돌, 연속 이동과 대각선 속도, 사거리 밖 검격의 빗나감/자동 접근 없음, 타격 프레임의 단일 피해, 입력 연타/쿨다운, 적 준비/검격/회복, 공격 유지로 적의 확정 검격을 무한 방해할 수 없음, 걸어서 공격 회피, 구르기의 무적/쿨다운, 적 추격, 승리/죽음 후 입력과 피해 종료, 재시작, 잘못된 시간 간격을 확인한다.

## 실제 3D 브라우저

1024×768에서 실제 WebGL, 새 성인 비례 관절 모델과 같은 모델의 초상을 확인했다. 키보드로 연속 이동하는 동안 다리 관절이 실제로 변한다. 바닥 탭으로 경로를 이동하고 기둥 위치는 목적지로 지정할 수 없다. 일시 정지와 재시작 확인 창에서는 시뮬레이션 전체 상태가 멈춘다. 취소/재시작/승리 후 재도전과 화면 이탈 시 정지·입력 해제를 검증한다.

CDP의 실제 touchStart/touchEnd로 이동 패드와 검격 버튼에 동시에 두 손가락 입력을 전달해 이동과 공격이 함께 작동하는 것을 확인한다. 회피로 실제 거리가 이동하고 쿨다운이 활성화된다. 적은 직접 추격하며 검격 버튼 유지로 실제 명중 다섯 번과 승리를 완료한다. 자동 접근/자동 반격 턴은 없다.

768×1024와 390×844에서 문서 스크롤, 버튼의 화면 경계와 최소 44px 크기, 실제 터치 이동/취소/회피를 확인한다. 실제 렌더 캡처는 `docs/screenshots/nox-actual-*.png`에 기록한다.

규칙 16개와 위 브라우저 검증이 모두 통과했다. 콘솔/페이지 실행 오류와 자산 HTTP 오류가 없었다.

첫 아트 실행의 indexed/non-indexed 메시 병합 오류를 정점 형식을 통일해 수정했다. 장식 추가 중 잘못 전달된 메시 scale 인자가 장면 생성을 중단한 문제도 수정했다. 로딩 검증은 DOM의 `arena` 이름 대신 실제 renderer가 생성됐는지 확인한다. 실패를 성공으로 취급하거나 테스트를 생략하지 않는다.

## 공개 배포

공개 HTTPS 바이트의 SHA256과 ES 모듈 MIME을 확인한 다음 동일 바이트로 직접 이동·회피·실시간 검격과 승리를 실행한다. 시스템 인증서 신뢰로 TLS를 검증하며 검증을 끄지 않는다. 이전 1.2 기록은 [과거 검증](verification-v1.2.md)에 보관한다.

2026-10-11 공개 검증 통과: 런타임 파일 13개가 소스와 일치하고 ES 모듈 MIME 형식이 정상이다. 공개 응답으로 직접 이동·회피·적 추격·검격 명중 다섯 번과 승리를 완료했다. 게임 소스 `20ca2c4`, 배포 `7c8f1bf8ed8d3b17a6f016f37816975bd59944cd`, GitHub Pages 실행 `38122474505`(성공). 주소: https://ureka01-creator.github.io/mmorpgboard/?release=2.0

## 범위와 제한

실제 iPad Safari, 기기 GPU 성능/배터리/절전 복원은 별도로 확인하지 않았다. 세계 렌더 해상도는 지속적인 느린 프레임에서 낮추며 HTML 조작/글자는 원래 해상도를 유지한다. 60Hz 시뮬레이션과 충돌 서브스텝으로 프레임 사이 벽 관통을 막는다.

새 관절 모델과 던전은 원본 코드로 구성한 스타일 3D 아트다. 생성한 녹스 방향 시안의 사실적인 모델·환경 밀도와 같은 품질을 구현한 버전이라고 설명하지 않는다. 한 구역·한 적·검격·회피 외의 RPG 시스템을 추가하지 않았다. 문 열기나 계단 이동은 아직 기능이 아니다.
