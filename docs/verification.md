# 2.5 캐릭터·보행·이동 중 회피 검증

2026-10-13. 17개 시뮬레이션 검사, 고정 자산·53관절·정규화된 가중치·8개 클립의 동작 검사 통과. 새 검사로 달리는 중 입력 방향으로 회피하고, 이동 입력을 유지하면 대기 프레임 없이 보행으로 돌아가며 쿨다운 동안 회피를 반복하지 못하는 것을 확인했다.

## 실제 스킨

120Hz 직접 검사: 최대 발 높이 0.2455m, 최저 발 높이 0.0180m, 몸 높이 보정 범위 -0.0001~0.0923m, 최대 프레임 관절 변화 0.3665rad. 이전 2.4의 몸 보정 범위는 -0.0519~0.1542m였다. 다리가 지면 아래로 내려가지 않도록 개별 보정하고 몸은 더 천천히 정착한다. 평균 접지 발목 이동은 0.0033m이며 이전의 0.0021m보다 크므로 발 미끄러짐의 모든 지표가 개선됐다고 설명하지 않는다. 해당 구간의 수치이며 완전한 발 접촉 물리는 아니다.

독립적인 캐릭터 뼈대와 실제 정점 변형, 발 디딤·회전·정지·공격 중 보행·뒷걸음·회피·피격·사망·재시작·로딩 실패 처리를 검사했다. 최대 발 높이 0.30m, 몸 보정 범위 0.12m, 신발 최저 높이 0.015m 기준을 추가했다.

## 입력과 게임

1024×768의 실제 WebGL에서 이동·탭 경로·충돌·정지/재시작·초상·두 손가락 이동/공격·회피·추격·검격 다섯 번과 승리·화면 이탈 시 해제를 검증했다. 이동 손가락을 누른 채 두 번째 손가락으로 회피 버튼을 누르고, 회피 손가락만 뗀 뒤에도 이동 입력과 보행이 유지되는 것을 확인했다. 회피 실행은 손가락을 떼기 전에 발생한다. 터치 검사에서 종료할 손가락을 잘못 지정하던 전송을 바로잡았다.

768×1024와 390×844에서 실제 터치 입력 해제·회피와 스크롤 없는 화면을 확인했다. 자동 검사는 실제 iPad Safari의 GPU 성능·배터리와 동일한 검증이 아니다.

이전 구현과 검증은 [2.4 기록](verification-v2.4.md)에 보관한다.
