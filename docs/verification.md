# v0.5 기능 검증

- `node scripts/verify_engine.cjs`: 캠페인 엔진 28개 시나리오 통과.
- `python3 scripts/verify_browser.py`: 터치 Chromium 105개 검사 통과.
- `node scripts/simulate_balance.cjs`: 시드 고정 용 전투 1,200회 완료. 기사 298/300, 마법사 276/300, 궁수 294/300, 사제 294/300 승리. Lv.4·공격 특성 3개·영웅 무기·희귀 갑옷과 장신구를 지급한 진단 조건이며, 승률은 실제 캠페인 밸런스의 기준이 아님.

## 검증 범위

수집·보고·보상 선택·호위·사냥·개인 경험치·장비 착용·특성 선택·두 봉인·최종 레이드의 전체 1인 UI 플레이. 상점과 동료 장비 전달, 휴식과 물약, 4인 차례 순환, 협동 전투 태세와 영웅별 에너지, 재굴림 소모와 제한, 후퇴, 전투 중 저장/이어하기, 승리 저장, 이전 기록 보존, 손상 기록 처리.

엔진에는 무효 행동 시 자원 보존, 산악 비용, 퀘스트 한도, 개인 보상과 참여 경험치, 레벨별 특성 배타 선택, 갑옷과 마법 저항, 출혈·재생·저주, 광역 반격, 용 격노, 회복 순서, 후퇴 시 피해 유지, 부활·전멸·시간 패배, 3라운드 사건과 저장 검증이 포함됨.

320×800, 390×844, 768×1024, 1024×768, 1024×1366, 1366×1024에서 지도/전투/파티/행동 조작의 경계와 문서 스크롤 없음 확인. 긴 퀘스트·가방·특성·규칙 목록과 많은 주사위·참여 영웅 목록은 내부 영역에서 열람 가능.

## 한계

전체 캠페인 UI 검사는 좋은 고정 주사위로 기능 경로를 검증함. 실패·반격은 별도 시나리오로 검사. 자동 시뮬레이션은 최고 수준 장비를 지급한 용 단독 전투임. 실제 iPad Safari, 사람의 캠페인 플레이 시간, 여러 성장 경로의 장기 재미와 밸런스는 아직 검증하지 않음.

배포 후 공개 HTTPS로 내려받은 HTML/CSS/JavaScript/일러스트의 SHA-256을 원본과 비교하고 해당 배포 바이트로 브라우저 검사를 재실행함. 클라우드 Chromium의 프록시 인증서 저장소 차이는 시스템 CA로 검증된 HTTPS 응답을 제공해 처리하며 TLS 검증을 끄지 않음.
