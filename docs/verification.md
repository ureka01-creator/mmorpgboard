# 2.8 이동·공격 검증

2026-10-14. 이동·공격 원화를 8방향 모두 새로 제작하고 실제 실행 렌더러로 검사했다. 목표는 좌우 발 교대, 동작 중 크기 고정, 준비→명중→복귀 연결, 완전한 검과 부츠의 표시다.

## 수정

- 8프레임 이동을 12프레임으로, 4프레임 공격을 7단계로 교체했다. 공격 시작·복귀는 같은 대기 그림을 공유한다.
- 전체 실루엣이나 검 끝으로 크기를 정하지 않고 머리·부츠와 3D 투영을 사용한다. 원화 장비를 머리로 오인하던 정렬도 수정했다. 동작별 확대율은 고정한다.
- 옆 자세의 검 끝이 UV 영역에 들어오는 경우를 행별 표시 메시로 제거했다. 원본 PNG는 변경하지 않았다.
- 바닥 아래로 투영되는 검·부츠의 깊이를 바닥 바로 위로 보정했다. 기둥·벽의 가림은 유지한다. 바닥 그림자는 부드러운 접지 표현으로 변경했다.
- 기존 이동 중 회피, 독립 터치 입력, 적의 준비→공격, 마지막 명중의 후속 동작을 유지한다.

## 결과

- 엔진 17개 검사 통과: 연속 이동, 충돌·경로, 공격 범위·피해·재사용 시간, 적 준비·추격, 이동 회피·무적, 승리·사망·초기화.
- 원본 10개와 안내·기준점 SHA256, RGBA 형식, 8방향, 96 이동 자세·56 공격 상태·32 회피 자세, 고정 확대율·표시 윤곽·대기 공유 검사 통과.
- 실제 Chromium WebGL: 모든 방향의 UV와 자세, 발 기준점, 독립 UV, 동일 거리 위상, 적 준비의 연속성, 첫 피해 시점의 베기, 마지막 피해 후 베기·복귀, 정지·초기화, 로딩 실패 UI 통과.
- 바닥 깊이 회귀 검사: 8방향×4공격 시점에서 바닥 추가 전후 캐릭터 픽셀 유지율 98% 이상. 실제 앞쪽 기둥을 추가하면 캐릭터 픽셀이 가려진다.
- 실제 조작: 키보드, 바닥 탭·충돌, 두 손가락 이동·공격, 이동 중 즉시 회피·이동 복귀, 다섯 번 명중과 승리, 결과창·초기화·화면 이탈 정지 통과.
- 1024×768, 768×1024, 390×844에서 화면 스크롤 없이 조작 가능하다. 세로 두 크기에서 실제 터치 이동·해제·회피도 검사했다.
- `scripts/review_refined_motion.py`로 8방향의 대기·12개 이동·7개 공격 상태를 실제 렌더했다. [진단 화면](motion-review-v2.8/direction-0.png)은 확대용 직교 카메라이며, [게임 화면](screenshots/nox-actual-walking.png)은 실제 던전 화면이다.

검증 환경은 Chromium 소프트웨어 WebGL이다. 실제 iPad Safari의 성능 측정은 포함하지 않는다. [이전 2.7 기록](verification-v2.7.md).
