# 2.4 보행 조정 검증

2026-10-12. 사용자 제공 7.09초 녹스 화면 녹화를 프레임으로 확인했다. 작은 캐릭터와 압축 때문에 정확한 관절 각도·걸음 주기를 역산했다고 설명하지 않는다. 방 안 이동·방향 전환을 정성적인 참고로 사용했다. 사용자 영상은 저장소나 배포에 포함하지 않는다.

## 변경

수평 보폭과 주기당 이동 거리를 함께 20% 줄이고 발의 공중 높이를 40% 낮춘다. 스윙 보정은 원래 자세의 무릎 굽힘 방향을 유지한다. 높이가 낮다는 이유만으로 앞으로 나가는 발을 지면에 고정하던 조건을 수정했다. 보정에 사용한 자세와 최종 IK 결과는 별도로 유지한다.

## 동작 검사

120Hz 직접 검사에서 최대 신발 높이 0.3111m(이전 0.5195m), 최저 높이 -0.0270m, 최대 프레임 관절 변화 0.3866rad, 접지 구간 평균 발목 이동 0.0021m를 측정했다. 이전 평균은 0.0014m였으므로 접지 오차가 모든 면에서 개선됐다고 설명하지 않는다. 최대 발 높이 0.36m 제한을 기존 스킨 브라우저 검사에 추가했다. 원본·파생 자산 해시, 53관절, 실제 정점 변형, 독립 뼈대, 이동 중 공격·뒷걸음·정지·회전·회피·피격·사망·재시작과 로딩 실패 처리를 검사한다.

규칙 검사 16개, 고정 자산/동작 검사와 실제 스킨 브라우저 검사 통과. 1024×768에서 연속 키보드 이동·경로·정지·재시작·동시 터치 이동/공격·회피·추격·검격 다섯 번과 승리를 검증했다. 768×1024, 390×844에서 실제 터치 입력 해제·회피와 스크롤 없는 화면을 확인했다. 이전 구현과 검증은 [2.3 기록](verification-v2.3.md)에 보관한다.

## 제한

몸의 상하 보정과 무기를 든 팔의 혼합은 남아 있다. 이것은 녹스와 동일한 동작을 완성한 버전이 아니라 짧은 보폭과 발 해제 시점을 조정한 버전이다. 실제 iPad Safari 성능과 모든 입력 상황의 시각적 자연스러움은 자동 검사만으로 확정할 수 없다.
