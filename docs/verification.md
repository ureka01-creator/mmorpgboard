# v0.4 기능 검증 결과

- 게임 엔진: 14개 시나리오 통과 (`node scripts/verify_engine.cjs`).
- 브라우저: 88개 검사 통과 (`python3 scripts/verify_browser.py`).
- 실행 환경: Chromium, 터치 및 모바일 화면 설정. 실제 iPad Safari 검증은 미실행.
- 전체 1인 플레이: 시작 → 세 지역 처치 → 봉인 3개 → 전리품 배분 → 레벨 3 → 용 소환 → 승리. 고정 주사위 결과로 검증.
- 4인: 직업 선택, 차례 교대, 적 단계, 다음 라운드 선 플레이어 순환 검증.
- 저장: 새로고침 후 지역 진행과 승리 상태 유지. 새 모험 취소 및 초기화 검증.
- 전투 UI: 자동 화면 전환, 지도 보기와 실제 후퇴, 전투 재진입, 주사위 눈·피해 표시, 반격, 처치 후 지도 복귀, 사제 치유, 물약 사용 후 공격 메시지가 나오지 않는지 검증.
- 팝업: 퀘스트·가방·규칙·영웅 카드 열기·닫기, 가방 닫기 후 키보드 포커스 복귀 확인.
- 신규 UI: 게임 소개, 일러스트 로드, 퀘스트 선택 및 목적지 표시, 행동 소모 없이 목표 변경, 첫 이동 추천, 완료 표시 검증.
- UI: 인접 칸 강조와 이동 제한, 사거리 밖 공격 비활성화, 목표 안내, 행동 소모, 게임 종료 후 행동 금지.
- 화면: 320×800, 390×844, 768×1024, 1024×768, 1024×1366, 1366×1024에서 지도·전투·행동 버튼이 화면 안에 들어오며 페이지 가로·세로 스크롤 없음.
- 배포용 ZIP: 웹 파일과 세 일러스트 목록과 압축 무결성 확인. 배포 전 로컬 무결성 확인.

난이도, 무작위 주사위 하의 승률, 실제 사람 간 플레이 시간은 검증하지 않았습니다. 외부 호스팅과 실제 Safari에서도 별도 확인이 필요합니다.
