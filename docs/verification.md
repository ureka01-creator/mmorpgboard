# 파티 RPG 1.0 검증 기록

검증 환경: 2026-10-11, Node 24, Python 3.12, Python Playwright + 시스템 Chromium. 별도 런타임 패키지 설치나 빌드가 필요하지 않은 정적 앱이다.

## 규칙과 진행

`node scripts/verify_rpg.cjs`: 17개 규칙/통합 테스트 통과.

- 경로가 벽과 점유를 우회하고 AP를 실제 경로 길이만큼 사용한다.
- 불가능한 이동, 시야/거리 밖 공격, 자원 부족, 중복 응답은 상태와 시각 효과를 변경하지 않는다.
- 대화 중 이동을 막는다. 설득 성공/실패에 따라 선금과 신뢰가 달라지고 실패해도 임무를 이어간다.
- 동료 모집, 명중/치명타/빗나감, 속박, 치유 상한, 방어의 실제 피해 감소와 AP 회복을 확인했다.
- 범위 공격으로 여러 적에게 피해를 주고 승리 시 쓰러진 동료를 빈 칸에서 회복시킨다. 적의 공격을 계속 방치하면 패배한다.
- 후퇴, 제한된 야영, 재진입, 수호석 회수, 마을 귀환과 보고를 확인했다.
- 전투/대화 저장을 직렬화해 복원하고 잘못된 체력·중복 살아 있는 위치·손상된 주사위 데이터를 거부한다.

같은 합법 행동 정책을 100개 난수 시드에 적용했을 때 3인 파티는 100승/0패, 검사 혼자는 98승/2패였다. 첫 교전은 쉬운 입문 전투다. 자동 정책은 진행 중단과 규칙 오류를 찾기 위한 것으로, 재미나 최종 난이도를 입증하지 않는다.

## 터치 화면과 전체 모험

`python scripts/verify_rpg_browser.py`: 브라우저 클릭으로 대화·설득 → 두 동료 모집 → 유적 전투 → 수호석 회수 → 귀환·보고를 완료했다. 전투의 행동력과 집중을 소모한 상태에서 새로고침하여 정확히 같은 상태로 이어졌으며 완료 저장도 복원했다. 브라우저 실행 오류는 없었다.

1024×768, 768×1024, 390×844, 320×568, 1180×820에서 실제 대화·모집·전투 진입을 실행했다. 화면 전체의 가로/세로 스크롤이 없고 하단 행동 메뉴가 화면 안에 있으며 전투 행동 버튼 높이가 44px 이상임을 확인했다. 긴 일지와 대화는 패널 내부에서 스크롤할 수 있다.

손상된 저장을 자동으로 덮어쓰지 않고 새 모험으로 복구할 수 있다. 이전 보드게임 저장 키는 유지한다. 저장소가 차단된 경우 플레이를 계속할 수 있고 자동 저장 불가를 알린다.

## 범위와 남은 확인

배경과 전신 캐릭터는 새 오리지널 생성 일러스트를 사용한다. 두 장소와 한 임무를 끝까지 연결한 시제품이다. 다중 임무, 장비/성장, 온라인 저장, 멀티플레이, 카메라 이동과 개별 적 행동의 순차 연출은 아직 구현하지 않았다. 장면의 그림과 격자 장애물의 정밀한 대응도 추가 개선 대상이다.

실제 iPad Safari 기기, 절전 후 복원과 손가락 조작감은 아직 확인하지 않았다. Chromium의 터치 입력·뷰포트 검증을 Safari 실기기 검증으로 간주하지 않는다.

공개 배포는 `scripts/verify_public.py`가 HTTPS로 받은 배포 파일의 SHA256을 소스와 비교하고, 그 동일한 파일로 브라우저에서 모험을 완료해 확인한다. 클라우드 Chromium의 프록시 인증서 저장소 문제를 피하기 위해 시스템 인증서로 HTTPS를 검증한 응답을 브라우저에 전달하며 TLS 검증을 끄지 않는다.
