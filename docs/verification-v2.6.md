# 2.6 새 캐릭터 아트 검증

2026-10-13. 3D 던전의 캐릭터를 새 방향별 RGBA 그림으로 교체했다. 기존 53관절 모델은 자세 안내 렌더용으로 남긴다.

- 시뮬레이션 17개: 연속 이동, 벽·기둥 충돌, 고속 회피의 관통 방지, 경로, 공격 타이밍, 적 공격, 이동 중 회피와 즉시 보행 복귀, 승리·사망·재시작.
- 자산 검사: PNG 10개 SHA256·RGBA·크기, 160개 실제 영역, 8방향·경계 여유, 이동 거리 위상, 공격 타격 프레임과 회피 시점.
- 실제 Chromium WebGL: GPU에서 그림이 표시됨, 실제 투명 픽셀, 64개 방향별 이동 그림, 32개 공격·32개 회피 그림 선택, 발 기준점, 독립 UV, 시간 정지·재시작과 로딩 실패 시 재시도 UI.
- 실제 입력: 이동·탭 경로·충돌·초상·정지·재시작·두 손가락 이동/공격·이동 중 회피·손가락을 유지한 보행 복귀·적 추격·검격 다섯 번과 승리·화면 이탈 입력 해제.
- 1024×768, 768×1024, 390×844 화면: 실제 터치 이동·취소·회피, 화면 밖 조작 없음, 44px 이상 터치 영역, 페이지 스크롤 없음.

검사 환경은 Chromium 소프트웨어 WebGL이다. 실제 iPad Safari의 성능과 애니메이션의 미적 자연스러움을 자동 검사로 보장하지 않는다. 그림 사이의 장비·형태 차이와 4프레임 회피의 한계가 남아 있다. GPU 표시 검사와 애니메이션 선택 검사는 원작과 같은 품질을 입증하는 검사가 아니다.

실제 플레이 화면은 `docs/screenshots/nox-actual-*.png`이며 목표 시안과 구분한다. 자세 안내와 기존 2.5 기록은 별도로 보관한다.
