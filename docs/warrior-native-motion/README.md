# 기사 모션 시안 수정 2 — 양발 교대와 방패 유지

공개 화면: https://ureka01-creator.github.io/mmorpgboard/warrior-motion.html?release=2.1

사용자가 지적한 걷기와 방패 누락은 실제 결함이었다. 이전 걷기 원화는 같은 발을 반복해 내밀었고, 공격 원화 일부에는 방패가 빠져 있었다. 이전의 로딩·재생·마네킹 관절 검사만으로는 이 문제를 잡을 수 없었다.

## 수정 내용

걷기는 24개 독립 그림의 다리와 광류 보간을 사용하지 않는다. 기존 시안 첫 프레임의 상체 외형을 유지하고, 허벅지·종아리·발의 고정 원화 부품을 Quaternius 원본의 실제 관절 위치에 따라 매 순간 배치한다. 한 주기에서 좌우 발이 번갈아 앞서며, 발목과 발끝도 각각 원본 관절을 따른다. 앞뒤 다리 순서와 무릎·발목의 부품 겹침 순서를 처리하고, 축소되는 세부 질감에는 밉맵을 사용한다.

방패는 공격 프레임에 그려진 장비에 의존하지 않는다. 방패가 없는 몸통 원화를 제작하고 방패를 독립 객체로 표시한다. 공격 원화의 왼팔 위치를 측정한 연속 앵커를 따라 이동하며, 전 구간에서 같은 객체와 불투명도를 유지한다. 걷기에서도 같은 독립 방패 객체를 사용한다. 방패가 검을 든 오른손으로 넘어가지 않도록 원화의 왼팔 위치를 기준으로 배치했다.

새 장비와 다리 원화는 기존 기사의 재질·색을 참고해 제작했다. `parts.png` 원본을 변경 없이 복사했으며, `parts.json`에는 연결된 8개 부품의 측정 UV 영역과 SHA256을 기록했다. 원본 PNG를 프로그램으로 다시 칠하지 않는다. 원래 게임의 승인된 원화와 실행 파일은 수정하지 않았다.

현재 화면은 **2D 원화 부품을 움직이는 시안**이다. 캐릭터 전체를 리깅한 3D 모델은 아니다. 공격 몸통은 여전히 24개 원화와 수치 보간을 사용하므로, 검 궤적·상체·망토 표현이 Nox 수준으로 완성됐다는 의미가 아니다.

## 이번 결함을 직접 검증

- 걷기 시작과 반 주기의 좌우 발끝 Y 차이는 원화 좌표 기준 +65.18 / -61.61px. 앞서는 발이 바뀐다.
- 기존 프레임 전환 경계 앞뒤 0.00001초의 발 위치 차이 최대 0.00685px. 그림 교체에 의한 다리 점프를 사용하지 않는다.
- 공격 한 주기 48개 시점에서 방패 객체가 유지되고 불투명도가 1이다.
- 같은 48개 시점에서 방패를 켠 화면과 끈 화면의 픽셀을 비교했다. 최소 색 차이 36.33으로, 객체 플래그뿐 아니라 실제 화면에 장비가 표시되는 것을 확인했다.
- 원본 비교 화면과 동일 시점의 53개 관절 위치·회전 오차 0.
- 재생·정지·속도·시점 조절, 1024×768 / 768×1024 / 390×844 / 605×800 화면에서 스크롤 없음, 브라우저 오류 0.
- [상세 결과](verification.json), [실제 재생 영상](paired-preview.mp4), [걷기 화면](walk-preview.png), [공격 화면](attack-preview.png).

모든 자동 검사는 이 시안에 대한 것이다. 실제 아이패드 성능이나 Nox와의 동작 일치를 검증한 것은 아니다.

## 재현

```sh
# 오프라인 원화 분석은 opencv-python-headless==4.12.0.88 필요
python scripts/prepare_warrior_equipment.py /path/to/generated-parts.png
python scripts/build_warrior_native_art.py --walk /path/to/original-preview-walk.png --attack /path/to/shieldless-attack.png
ARENA_BASE=http://127.0.0.1:8044/ python scripts/verify_warrior_native_art.py
```

원본 동작은 Quaternius CC0이며 `assets/animation-resources/quaternius/LICENSE`에 라이선스를 보관한다. 새 원화의 해시와 생성 파일명은 `assets/sprites/native-motion/manifest.json`, `parts.json`에 있다. Nox 원본 그림은 포함하지 않는다.
