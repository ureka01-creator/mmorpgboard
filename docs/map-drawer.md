# v0.8 전체 화면 지도와 하단 메뉴

2026-10-11. 탐험 화면의 고정 헤더·옆 패널·하단 행동 영역을 접고 펼치는 하단 메뉴로 옮겼다. 지도는 브라우저의 사용 가능한 화면 전체에 표시하며, Safari 도구 모음을 숨기는 기기 전체 화면 기능은 사용하지 않는다.

- 처음과 새로고침 후: 지도, 작은 영웅 상태 버튼, 하단 메뉴 손잡이.
- 메뉴 손잡이 또는 영웅 상태 버튼: 퀘스트·영웅·상점·규칙·파티·지역 정보·행동 표시.
- 지역 선택: 이동 조건과 비용을 표시하는 메뉴가 열림. 선택만으로 이동하지 않음.
- 이동·조사·휴식·차례 종료 성공: 메뉴가 접히고 지도 전체를 다시 확인.
- 조건 부족: 행동을 막고 비용/조건을 열린 메뉴에서 확인.
- 지도 빈 공간, 「지도 보기」, Escape: 메뉴 접기. 접힌 메뉴는 `inert`로 키보드 탐색에서도 제외.
- 전투: 기존 별도 테이블로 전환. 종료하면 다시 전체 화면 지도와 접힌 메뉴.

지도와 경로 좌표는 메뉴 상태에 영향을 받지 않는다. 기존 컨트롤을 옮겨 사용하므로 게임 규칙과 저장 형식은 변경하지 않는다. 열고 닫기는 행동·자원 소모나 저장 변경을 일으키지 않는다. 작은 화면에서는 행동을 두 줄로 표시한다. 긴 카드 내용은 메뉴/팝업 안에서만 스크롤한다.

## 검증

기존 전체 캠페인 터치 검사 138개, 기술·보상 개편 검사 82개 통과. 신규 `scripts/verify_map_drawer.py` 46개 검사: 접힌 컨트롤의 키보드 접근 차단, Escape 초점 복원, 이동 확인과 자동 접힘, 퀘스트 접근, 저장 복원, 차례 진행, 조건 거부, 전투 진입/복귀, 지도 크기 고정과 메뉴 버튼 경계.

320×800, 390×844, 768×1024, 1024×768, 1024×1366, 1366×1024에서 지도는 (0,0)부터 화면 전체를 차지하고, 메뉴를 펼쳐도 좌표와 크기가 그대로임을 확인했다. 페이지 스크롤과 잘린 하단 버튼이 없음을 확인했다. 실제 iPad Safari 기기 검사는 별도다.
