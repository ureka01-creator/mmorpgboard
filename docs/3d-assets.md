# 2.7 캐릭터 동작 보정

던전은 기존 Three.js 3D 지형을 유지하며, 캐릭터는 카메라를 향하는 수직 평면에 투명 RGBA 그림을 표시한다. 기존 다각형 캐릭터는 실행 장면에서 사용하지 않는다. 성인 비례의 짧은 갈색 머리, 붉은 스카프, 사슬 갑옷, 가죽 장비, 검과 방패를 가진 독자 캐릭터다. Nox의 게임 파일이나 영상에서 그림을 추출하지 않았다.

OpenAI 이미지 생성으로 제작한 원본 1536×1024 PNG 10개에 대기 4, 이동 8, 공격 4, 회피 4 프레임이 8방향으로 들어 있다. 총 160프레임이며 `warrior.json`에 원본 SHA256, 방향, 그림 영역과 발 기준점을 기록한다. 캐릭터별 UV와 재질은 독립적이고 수호병은 차가운 색으로 구분한다.

이동 그림은 이동 거리를 기준으로 순환한다. 정지와 충돌 시 이동 거리가 늘지 않아 다리만 달리지 않는다. 방향 경계에 작은 여유를 두어 그림이 왕복하지 않게 한다. S·SE·E·NE·SW 공격은 원화 2번, N·NW·W는 원화 3번이 실제 베기 그림이다. 영웅의 0.26초·수호병의 0.18초 타격 시점에 방향에 맞는 그림을 표시한다. 적은 0.72초 준비 끝에 이미 든 검을 다시 내리지 않는다. 검격 끝에는 검을 내린 대기 자세로 복귀하고, 마지막 명중에도 0.40초 동안 남은 베기·복귀를 표시한 뒤 승리창을 띄운다.  이동 중 회피가 끝나면 입력을 유지한 방향으로 걷는다. 깊이 검사를 사용해 기둥 뒤의 캐릭터가 가려진다.

`docs/pose-guides`는 기존 Luana Coppio의 CC0 스킨과 Quaternius CC0 동작을 실제로 렌더링한 자세 안내다. 생성 그림의 실제 투명 영역을 분석해 발·검을 잘라내지 않고 UV 영역을 정한다. 초기 안내 자세 기반 크기 추정은 검 끝과 발 위치에 따라 프레임별 확대율이 흔들렸다. 2.7은 방향별 보행의 중간값으로 픽셀당 월드 크기를 정하고 해당 방향의 이동·공격 전체에 같은 값을 적용한다. 기존 추정은 `guideWorldHeight`로 남긴다. 이 보정은 프로그램의 확대율 변화에 대한 수정이며, 그림 자체의 얼굴·장비·신체 비례가 같아지는 보정은 아니다. `scripts/bundle_sprite_assets.py`는 픽셀을 분석하고 원본 파일을 복사하며 새 그림을 그리거나 PNG를 다시 저장하지 않는다. `scripts/render_pose_guides.py`는 자세 안내의 렌더러다. 이전 모델과 동작 라이선스는 원래 경로에 보관한다.

이미지 생성 결과에는 프레임 사이 장비·형태의 차이가 남아 있다. 8프레임 이동과 4프레임 검격·회피는 첫 적용 범위이며 원작과 동일한 애니메이션 품질을 의미하지 않는다. 피격은 투명도 변화, 사망은 쓰러지는 회피 그림과 페이드로 표현한다. 별도 사망·피격 그림과 적 전용 아트는 아직 없다.
