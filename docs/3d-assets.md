# 2.8 이동·검격 아트

갈색 머리, 붉은 스카프, 사슬 갑옷과 가죽 장비, 오른손 검·왼손 방패를 가진 독자 캐릭터다. Nox 리소스를 추출하거나 복제하지 않았다. 3D 지형 위에 카메라를 향하는 방향별 투명 그림을 표시한다.

`assets/sprites/refined/direction-0.png`부터 7까지는 OpenAI 이미지 생성으로 제작한 원본 1536×1024 RGBA PNG다. 각 시트의 상단 세 줄은 대기 1·이동 12·보조 대기 2, 하단은 검격 7 자세다. 실제 실행은 대기 1, 이동 12, 검격 7단계를 사용하며 검격의 첫·마지막 자세는 대기 원화를 공유한다. 별도로 기존 `warrior/dodge-front.png`, `dodge-back.png`의 회피 4프레임을 유지한다. 방향별 24개 상태, 총 192개 상태와 176개 독립 영역이다. 보조 대기와 중복 검격 대기 그림은 실행하지 않는다.

`docs/pose-guides-v2.8`은 기존 CC0 스킨을 실제로 렌더링한 자세 안내다. 공격 자세는 팔·다리 IK로 제작했다. 발을 접지하고 검의 준비·베기·복귀를 연결한다. 모든 방향에서 칼날과 부츠가 안내 화면 안에 들어오는지 확인했다. 안내 생성은 `scripts/render_refined_pose_guides.py`로 재현한다. 기존 CC0 저작자·라이선스는 원래 자산 폴더에 보존한다.

`warrior.json`은 원본 PNG와 안내의 SHA256, UV 영역, 머리와 부츠 기준, 바닥 기준점, 동작별 고정 확대율과 표시 윤곽을 기록한다. 머리를 다른 장비로 오인하던 템플릿 매칭을 갈색 머리 영역 식별로 교체했다. 머리·부츠 간격을 3D 자세의 투영과 비교해 방향별 이동·검격의 중간값으로 확대율을 고정한다. 칼날 길이는 캐릭터 크기와 발 위치의 기준으로 사용하지 않는다.

원본 PNG를 다시 그리거나 변환하지 않는다. `scripts/bundle_refined_sprites.py`와 `sprite_landmarks.py`는 픽셀을 읽고 원본을 복사하며 JSON을 작성한다. 행별 표시 영역으로 평면 메시를 구성해 이웃 자세의 검 끝이 UV 사각형 안에 들어와도 표시하지 않는다. 검이 부츠 아래로 투영되는 픽셀은 바닥 바로 위의 깊이를 사용하고 기둥·벽의 가림은 유지한다. 부드러운 바닥 그림자는 별도 생성 재질이다.

원본을 다시 묶는 명령:

```sh
python scripts/bundle_refined_sprites.py --sources docs/pose-guides-v2.8/sources.json --guides docs/pose-guides-v2.8
```

이동은 2.24m 거리 주기로 12프레임을 순환한다. 정지·충돌에서는 주기가 진행되지 않는다. 영웅 명중은 0.26초, 수호병은 0.18초이며 모두 검격 4번 자세다. 수호병의 준비 자세는 공격 시작까지 유지한다. 마지막 명중도 베기와 복귀를 끝낸 후 승리 화면이 열린다. 별도 피격·사망 원화는 이번 변경에 포함하지 않으며 기존 표현을 유지한다.
