# 파티 RPG 제작 기획

## 방향과 첫 모험

목표는 공간을 탐험하면서 대화·동료·전투 선택이 결과를 바꾸는 오리지널 CRPG다. 발더스 게이트 계열에서 참고하는 것은 파티의 역할 분담과 선택 중심의 모험 구조다. 그 작품의 세계관, 캐릭터, 이야기나 D&D 규칙을 옮기지 않는다.

1.0의 제작 단위는 마을에서 출발해 수호석을 되찾는 하나의 완결된 모험이다. 기존의 추상 지역 노드 이동·주사위 배분 보드게임은 현재 앱에서 제거했다. 배경은 세밀한 일러스트를 사용하고 화면의 중심은 장소와 인물이다.

## 1. 탐험 화면

현재: 마을과 유적, 인물·야영지·출구·수호석, 일행 이동, 통과할 수 없는 장애물, 인접 상호작용. 월드가 화면을 채우고 위치·목표를 위쪽, 파티·행동을 아래쪽에 둔다. 화면 전체의 스크롤은 발생하지 않는다. 장애물 표시가 이동과 시야 규칙에 연결된다.

다음: 더 넓은 장면의 카메라 이동, 문·상자·숨겨진 통로, 조사 가능한 소품과 환경 단서. 장면의 시각적 통로와 격자 장애물을 더욱 정밀하게 일치시킨다. 지형 장식이 실제 통행 가능 여부를 혼동시키면 안 된다.

## 2. 대화와 선택

현재: 촌장의 요청에 도움·설득·위협 중 선택. 선금과 신뢰가 달라지며 마지막 보상에 반영된다. 설득 실패로 모험을 중단시키지 않는다. 동료 두 명에게 직접 동행을 부탁한다.

다음: 선택마다 인물의 반응·관계와 해결 경로가 달라지는 분기. 특정 동료가 있으면 대화 선택지가 열린다. 같은 결말에 이르는 장식적 선택만 늘리지 않는다.

## 3. 파티와 영웅

현재: 검사 아렌, 마법사 리엔, 치유사 세라. 체력·AP·집중·사거리와 기술이 다르다. 각자의 행동력을 따로 사용하고 파티 카드로 선택한다.

다음: 동료의 성격·관계, 장비와 기술 성장. 한 번에 성장·제작·상점·스킬 트리를 모두 추가하지 않고 다음 모험에서 얻는 하나의 새 능력부터 검증한다.

## 4. 전술 전투

현재: 탐험에서 유적에 들어가면 같은 장소에 전투 격자·이동 범위·행동 메뉴가 나타난다. AP 4, 이동 1칸 비용 1, 공격/기술 2, 방어 1. 벽·점유·시야를 판정한다. 속박으로 적 이동을 막고 치유·방어로 일행을 유지한다. 공격의 d20은 저장된 실제 판정을 표시한다. 적은 길찾기로 살아 있는 일행에게 접근한다.

다음: 전투 진입 카메라·개별 타격과 적 행동의 순차 연출, 사거리/시야/피해 예측을 더 직접적으로 표시. 고저차·측면·환경 상호작용 중 하나를 추가해 위치 선택의 이유를 강화한다. 주사위 연출은 판정 결과를 바꾸거나 행동을 재실행해서는 안 된다.

## 5. 임무와 결말

현재: 임무 수락 → 유적 전투 → 수호석 회수 → 귀환 → 보고. 신뢰에 따라 보고 보상이 달라진다. 전투 승리 후 쓰러진 동료는 체력 4로 일어난다. 후퇴하면 골드 2를 잃고 마을로 귀환하며 적은 다음 방문에 회복한다. 야영은 보급 두 번으로 제한한다.

다음: 힘·대화·우회 중 둘 이상의 해결 경로와 그에 따른 장소/인물 변화. 전투 없이 끝내는 선택도 실제 임무 완료로 이어져야 한다.

## 6. 저장과 조작

현재: 모든 성공한 행동을 브라우저에 자동 저장. 전투·대화·결말에서 이어하기. 잘못된 저장은 자동 덮어쓰지 않는다. 새 모험은 확인한다. 터치 기준 행동 버튼 최소 높이 44px, 태블릿 두 방향과 소형 화면 배치 검증.

다음: 저장 내보내기/가져오기, 슬롯, 되돌아보기 가능한 대화 기록. iPad Safari 실기기에서 터치·주소창·절전 후 재개를 별도로 확인한다.

## 다음 버전의 판단 기준

자동 검증은 진행 가능성과 규칙 일관성을 확인한다. 재미는 실제 플레이에서 판단한다. 다음 버전은 선택의 차이가 눈에 보이는지, 전투에서 이동과 기술을 선택할 이유가 생기는지, 설명 없이 목표와 대상이 읽히는지를 중심으로 개선한다. 새 장소 수보다 한 모험의 선택과 연출을 먼저 깊게 만든다.
