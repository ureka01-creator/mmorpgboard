# v0.7 개편 구현과 검증

2026-10-09. 승인받은 탐험·전투·보상 시안의 첫 구현이다. 기획 전체가 완성되었다는 의미는 아니다.

## 구현 범위

- 넓은 지역 지도와 경로, 지역 카드의 이동/교전 행동, 작은 파티 카드. 가로·세로 배치 분리.
- 직업별 기본 기술 3개 + Lv.3 기술 1개, 주사위 배치·취소·대상 선택·재사용 대기.
- 주사위의 여섯 면과 눈, 색/문양 구분, 굴림·공격·반격 연출과 빠르게 보기·동작 줄이기.
- 공격·방어·회복·반격 후 HP 미리보기, 별도의 에너지 재굴림 모드.
- 전투 승리 화면과 삽화가 있는 퀘스트 보상 비교 카드.
- 기사 연습 전투, 기존 캠페인의 메모리/저장 격리, 원본을 수정하지 않는 v2→v3 키 복사.
- 자체 지도, 기사 기술 삽화와 각 장비 12종에 맞는 개별 삽화 추가. 다른 직업 기술은 해당 직업의 기존 초상 삽화를 사용한다.

| `verify_tactics.cjs` | 배치 비용·중복·소유권·조건·대상·쿨다운·미리보기·불법 저장 | 14 시나리오 통과 |

| `verify_redesign_browser.py` | 기술 배치·취소·재굴림·협동 대상·보상·연습 격리·연출 중 저장 | 82 검사 통과 |

화면 크기: 320×800, 390×844, 768×1024, 1024×768, 1024×1366, 1366×1024. 페이지 스크롤, 지도 좌표와 SVG 경로 일치 설정, 카드/하단 버튼 겹침, 핵심 준비·재굴림 44px 터치 높이를 확인했다. 긴 목록과 많은 주사위는 해당 패널 내부에서 스크롤한다.

같은 실행 버튼을 빠르게 두 번 눌러도 교전은 한 번만 진행하며, 연출 도중 새로고침해도 이미 확정한 결과를 복원한다. 연습 전투는 실제 기록을 바꾸지 않고 진행 중인 실제 전투로 돌아갈 수 있다. 손상된 기록은 새 모험 화면에서 처리하며 원본은 자동 삭제하지 않는다.

## 수치 진단과 한계

`simulate_tactics.cjs`: 동일한 시드로 직업 4종 × 정책 3종 × 200회, 총 2,400회. 장비 없는 Lv.1, HP 8 늑대, 강습, 재굴림 없는 조건. 기본 공격만/기술 피해 우선/기술 생존 우선 정책을 비교했다. 기술 정책의 승률은 99~100%로 첫 적이 입문용으로 쉽다. 생존 정책은 같은 승률에서도 남는 체력을 개선하며, 사제는 치유 선택으로 교전 길이가 조금 늘어난다. 짧은 연습 적은 HP 14로 별도 구성한다.

`simulate_balance.cjs`는 기존 Lv.4·최고 공격 장비·공격 특성 조건의 용 전투 1,200회를 별도로 유지한다. 기술을 사용하지 않는 기존 정책의 호환성을 확인하는 진단이다. 둘 모두 사람의 재미·숙련도·실제 여행 자원 운용을 입증하지 않는다.

실제 iPad Safari 기기 검사와 사람의 플레이 피드백은 아직 수행하지 않았다. 소리, 실제 물리 주사위, 기술 장착 슬롯, 신규 위협 트랙, 진영 경쟁은 구현하지 않았다. 개별 기술의 밸런스와 본 캠페인의 시간/난이도는 후속 플레이테스트 대상이다. 시안의 모든 장식과 삽화를 그대로 복제한 화면은 아니며, 실제 터치 영역과 읽기 쉬운 텍스트를 확보해 구성했다.
